# DLMMDD Workshop: Synthetic Image Attribution Challenge

---

## Overview
The **Synthetic Image Attribution Challenge** is organized within the *Workshop on Deep Learning and Mathematical Methods for Deepfake Detection (DLMMDD)* at the **35th International Conference on Artificial Neural Networks (ICANN) 2026**, held on **September 14–17, 2026** in **Padua, Italy**.

The challenge addresses the rapidly evolving problem of **Synthetic Image source Attribution (SIA)**. Its primary objective is to foster the development of novel, robust, and reproducible methodologies for fake image attribution under controlled experimental conditions.

Specifically, the competition is conducted on a newly released ad-hoc attribution dataset comprising face images generated by state-of-the-art text-to-image models.

---

## Dataset Description
The dataset is composed of **10,000 face images** generated by **10 open-source text-to-image models** (all available on Hugging Face). The dataset is perfectly balanced among the sources, with each model contributing exactly **1,000 images**.

* **Prompts Source:** The prompt list was taken from the **WILD dataset** to generate new face images.
* **Dataset Splits:**
  * **Training Set:** 7,000 labeled images.
  * **Test Set:** 3,000 unlabeled images (ground-truth labels remain private).

### Test Set Post-Processing
To simulate real-world scenarios, all images in the test set have undergone **1 to 3 post-processing operations** randomly selected from the following set:
* JPEG compression
* WebP compression
* Random central crop
* Resizing
* Small rotation with aspect-preserving crop
* Contrast/brightness adjustment
* Gaussian blur
* Grayscale conversion
* AI super-resolution using pre-trained models
* JPEG AI compression

> [!IMPORTANT]
> The exact post-processing operations applied to any given test image are **not disclosed** and must be handled implicitly by your model's robustness.

## Directory & File Structure
The project dataset files are structured as follows:

```text
.
├── Data/
│   │   Data/
│   ├── Training/
│   │   ├── 0.png
│   │   ├── 1.png
│   │   └── ... (7,000 training images)
│   ├── Test/
│   │   ├── 6.png
│   │   ├── 12.png
│   │   └── ... (3,000 test images)
│   ├── training.csv
│   ├── test.csv
│   ├── sources.txt
│   └── sample_submission.csv
└── sample_submission.csv
```

### File Breakdown
* **`sources.txt`**: A text file matching the source class index to the generator name.
* **`training.csv`**: Contains metadata and labels for the training set.
  * *Columns:* `ID`, `path` (file path), `y` (ground truth class label, `0-9`).
* **`test.csv`**: Contains metadata for the test set.
  * *Columns:* `ID`, `path` (file path).
* **`sample_submission.csv`**: A template submission file.
  * *Columns:* `ID`, `TARGET` (random predictions).

---

## Evaluation & Leaderboard
The evaluation metric for this competition is **Classification Accuracy**.

* **Closed-Set Classification:** The problem is treated as a 10-class single-label classification task.
* **Leaderboard Split:**
  * **Public Leaderboard (50% of the test set):** Used for fast feedback during the active competition phase.
  * **Private Leaderboard (50% of the test set):** Used for final evaluation to determine the official rankings. This is released after the competition closes.

---

## Submission Format
Submissions must be a CSV file containing exactly two columns: `ID` and `TARGET`. The rows do not need to be in any specific order, but the association between `ID` and `TARGET` must be strictly maintained.

```csv
ID,TARGET
201,0
234,7
172,4
...
```

> [!TIP]
> **To avoid row misalignment errors:** 
> Load `test.csv` as a pandas DataFrame, append your predicted class labels as a new `TARGET` column, drop the `path` column, and save the result as a CSV file.
> ```python
> import pandas as pd
> 
> # Load test metadata
> test_df = pd.read_csv('Data/test.csv')
> 
> # Add your model predictions (example)
> test_df['TARGET'] = predictions
> 
> # Keep only submission columns and export
> submission_df = test_df[['ID', 'TARGET']]
> submission_df.to_csv('submission.csv', index=False)
> ```
